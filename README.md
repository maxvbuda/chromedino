# chromedino

The real Chrome "offline dinosaur" (T-Rex Runner) game, extracted from the Chromium source and served as a standalone page.

Press Space / Up to jump, Down to duck.

Based on [wayou/t-rex-runner](https://github.com/wayou/t-rex-runner) (BSD-3-Clause, see [LICENSE](LICENSE)), which extracts the game directly from Chromium's `components/neterror/resources/offline.js`.
